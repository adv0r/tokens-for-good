The framework keeps an explicit allow/deny list of repositories. Real
maintainer handles are anonymized as `maintainer-A`, `maintainer-B`, …
All quotes are verbatim from public PR threads.

- 📋 **[Rendered policy table](https://github.com/adv0r/tokens-for-good/blob/main/kb/repos-policy.md)** on GitHub.
- 🧾 **[YAML source](https://github.com/adv0r/tokens-for-good/blob/main/kb/repos-policy.yaml)** on GitHub.

If you are a maintainer and want your repo on the blacklist (or your
quote removed), see
[`MAINTAINER_REMOVAL.md`](https://github.com/adv0r/tokens-for-good/blob/main/MAINTAINER_REMOVAL.md).
The opt-out is honored within 24h — see the dashboard's
"Opt-outs honored" counter for public compliance tracking.
