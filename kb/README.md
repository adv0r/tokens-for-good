# `kb/` — knowledge base

This folder holds **facts**, not procedures. Every file here is meant to be
read by future agent sessions (and by humans) to avoid repeating mistakes
and to preserve community context across runs.

The actual mutable state (PR list, helpful-signal counts, event log) lives
locally in `~/.local/share/token-for-good/state.db` (SQLite). The schema
for that database is at [`../schema/state.sql`](../schema/state.sql).

## Source-of-truth split

Some `kb/` files are **YAML** (machine-readable, the source of truth) and
some are **Markdown** (human-readable, regenerated from the YAML by
`scripts/tfg`). Don't hand-edit the rendered `.md` files — they get
overwritten on the next render.

| File | Kind | Source of truth | Regenerated by |
|---|---|---|---|
| `contribution-types.yaml` | YAML | itself | — (hand-edit) |
| `repos-policy.yaml` | YAML | itself | — (hand-edit) |
| `repos-policy.md` | rendered | `repos-policy.yaml` | `tfg policy render` |
| `lessons.yaml` | YAML | itself | — (hand-edit) |
| `lessons.md` | rendered | `lessons.yaml` | `tfg lessons render` |
| `pr-history.md` | rendered | `state.db` | `tfg pr-history render` |
| `maintainer-patterns.md` | hand-written narrative | itself | — (hand-edit) |
| `ai-detection-tools.md` | hand-written narrative | itself | — (hand-edit) |

## How an agent should use this folder

1. **Before contributing**: run `tfg vet <org/repo>`. This already reads
   `repos-policy.yaml` and applies the blacklist + cooldown gate.
2. **Before designing a fix**: read `contribution-types.yaml` to know which
   types are PR-eligible vs issue-only, and what the per-type probe cap is.
3. **Before crafting a PR**: skim `lessons.md` (or query `lessons.yaml`
   programmatically) for any rule whose `status` is `confirmed` or `active`.
4. **After a session**: `tb-self-improve` reads the events log, proposes
   lifecycle bumps, and you re-render the markdown files.

## Editing rules

- **Anonymized maintainer ids.** All public files use `maintainer-A`,
  `maintainer-B`, etc. The mapping to real handles lives **only** in
  `~/.local/share/token-for-good/maintainer-map.json`.
- **Quotes are verbatim.** Never paraphrase, never trim mid-sentence. If
  paraphrasing is the only option, prefix with `(paraphrase)`.
- **Cite sources** for every policy entry — at minimum the PR URL (PR URLs
  are public).
- **Confidence labels** for lessons: `LOW` (1 data point), `MEDIUM` (2–3),
  `HIGH` (≥4 independent confirmations).
- **No private info.** Do not include emails or DMs even if a maintainer
  shared them in a comment thread.
