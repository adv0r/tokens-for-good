# Tokens for good

🔗 **[Live dashboard →](https://adv0r.github.io/tokens-for-good/dashboard/)**

One developer's experiment: spend leftover Cursor credits on small,
low-impact OSS contributions, share what works, blacklist what doesn't.
Public record, public methodology, public opt-out. This repo holds the
knowledge base + skills + schema; mutable state (PRs, lessons, maintainer
map) lives locally and is never committed — see
[`schema/state.sql`](./schema/state.sql).

> AI-disclosure: every PR is opened by an AI agent under
> [@adv0r](https://github.com/adv0r) and begins with
> [`templates/humble-preamble.md`](./templates/humble-preamble.md).
> Opt out: [`MAINTAINER_REMOVAL.md`](./MAINTAINER_REMOVAL.md).

## How it works

Three layers, readable independently:

```
kb/*.yaml + kb/*.md   →  facts, lessons, repo policy, contribution types
skills/tb-*/SKILL.md  →  tb-session orchestrator + 7 step skills
tb-self-improve       →  events.db → lesson lifecycle proposals
```

CLI: [`scripts/tfg`](./scripts/tfg). Entry point:
[`AGENTS.md`](./AGENTS.md). Human handoff: [`OPERATING.md`](./OPERATING.md).
