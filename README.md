# Tokens for good

A transparent record of one developer's experiment: spending leftover
Cursor credits at the end of each billing cycle on small, useful,
**low-impact** open-source contributions, and sharing what we learn.

The repo is both the **operational brain** for the AI agent (knowledge
base + skills + state schema) and a **public artifact** for maintainers,
agent operators, and curious passers-by. The actual mutable state — which
PRs are open, which lessons are confirmed, who closed what — lives
**locally**, not here. See [`schema/state.sql`](./schema/state.sql).

> **AI-disclosure**: this repo is run by an AI agent under
> [@adv0r](https://github.com/adv0r). Every PR opened by the agent begins
> with the disclosure preamble in
> [`templates/humble-preamble.md`](./templates/humble-preamble.md).
> Maintainers can opt out at any time — see
> [`MAINTAINER_REMOVAL.md`](./MAINTAINER_REMOVAL.md).

## How it works

Three layers, each meant to be readable independently:

```
┌────────────────────────────────────────────────────┐
│ 1. Knowledge base   (kb/*.yaml, kb/*.md)           │
│    facts, lessons, repo policy, contribution types │
└──────────────────────────┬─────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────┐
│ 2. Skills           (skills/tb-*/SKILL.md)         │
│    tb-session orchestrator + 7 step skills         │
└──────────────────────────┬─────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────┐
│ 3. Self-improve loop (tb-self-improve)             │
│    events.db → proposes lesson lifecycle bumps     │
└────────────────────────────────────────────────────┘
```

The CLI [`scripts/tfg`](./scripts/tfg) ties them together. See
[`AGENTS.md`](./AGENTS.md) for the agent entry point and
[`OPERATING.md`](./OPERATING.md) for the human handoff.

## Disclaimers

- This is a **personal experiment**, not a product. There is no upsell,
  no funnel, no business behind it.
- The AI agent is not always right. PRs are reviewed by a human before
  push when running in confirmed/interactive mode; in `--auto` mode the
  surface is restricted to tier-1 typo/broken-link fixes in repos already
  marked `friendly`.
- We don't try to defeat AI-detection tools. If your repo uses
  AgentScan-style automation, we want to recognize the signal and stay
  away.
- All maintainer quotes are verbatim from public PR threads. Real handles
  are stored only locally; the public files use anonymized ids.
