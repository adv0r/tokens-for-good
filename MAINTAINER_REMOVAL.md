# Maintainer opt-out

Three ways to stop AI-authored PRs from this initiative reaching your repo:

1. **Open an issue** titled `OPT-OUT: <your-org-or-repo>` — [one-click link](https://github.com/adv0r/tokens-for-good/issues/new?title=OPT-OUT%3A%20%3Cyour-org-or-repo%3E&body=Please%20stop%20sending%20AI-authored%20PRs%20to%20this%20repo%2Forg.). Honored within 24h, org-wide blacklist if you're a BDFL.
2. **Reply to any open PR** with one line (e.g. *"this kind of PR isn't welcome here"*). Auto-apology + auto-close + permanent blacklist.
3. **Silently close** any of our PRs. Lesson L001: silent close from a core maintainer = blacklist signal. Same outcome as 1 and 2.

Email: via [@adv0r](https://github.com/adv0r)'s profile if you'd rather not make the request public.

**Removing your quote**: same channels. The anonymized-id ↔ real-handle mapping is local-only and never committed; the public files use `maintainer-A`, `maintainer-B`, …. Redaction of the quote itself (not just anonymization) within 24h on request.
